# Credits: third-party UI sources

Components and themes adapted from 21st.dev (and other sources) for the Interim UI revamp. Each adapted file also carries a header comment with its source URL and author. Format: `- **Name** (what) by author: URL. Where it is used; what we changed.`

- **Sea Glass** (theme, starting palette) by serafimcloud: https://21st.dev/community/themes/sea-glass. Used in `src/styles/tokens.css`; structure and shadcn roles kept, every value replaced with the audit's contrast-safe tokens (teal accent, Inter/Atkinson fonts, larger radii, no dark block).
- **Accessible Radio Group** (radio group) by a11ypros: https://21st.dev/r/a11ypros/a11y-radio (21st.dev demo 34674, MIT, ported from A11Y Pros a11y-radio). Used in `src/ui/kiosk/answer-group.tsx`; kept native radios, labelled group, helper/error in aria-describedby and the role=alert error; changed to fieldset/legend with role=radiogroup, roving tabindex with arrow/Home/End keys, 64px full-row tap targets, solid #115E59 selected fill with a check icon, blue focus ring, kiosk tokens only.
- **Radio Group 8** (visual reference only, not retrieved) by sean0205: https://21st.dev/@sean0205/components/c-radio-group-8. Row-style option look for `src/ui/kiosk/answer-group.tsx`; no code taken.
- **Progress Bar Stepper** (stepper) by sean0205: https://21st.dev/@sean0205/components/c-stepper-11 (21st.dev demo 29801). Used in `src/ui/kiosk/progress.tsx`; kept the thin rounded segments filled up to the current step; removed step titles, tablist triggers, click-to-jump and the context/panels; added one visible counter, a single role=progressbar and a polite live announcement.
- **Glass Button** (button) by jahed: https://21st.dev/community/components/jahed/glass-button (21st.dev demo 4922). Used in `src/ui/button.tsx`; kept the frosted light-edged look (now the `glass` variant via `.glass-strong`) and the cva variant/size split; removed the animated conic border, 3D press, scale-on-hover, text-shadow sheen and injected `<style>`; added primary/secondary/ghost/danger/destructive variants, console sm/md/icon and kiosk xl sizes, loading/aria-busy, asChild.
- **Liquid Glass Card** (card) by designali-in: https://21st.dev/community/components/designali-in/liquid-glass-card (21st.dev demo 3206; original https://ui.dalim.in/card). Used in `src/ui/glass-card.tsx`; kept the shadcn Card anatomy (Header/Title/Description/Action/Content/Footer, data-slots); removed the SVG turbulence/displacement backdrop filter, nine stacked inset shadows, outer glow, transition-all and dark block; glass now comes from the token `.glass` / `.glass-strong` utilities with a solid fallback; added `as` element and automatic aria-labelledby from the title.
- **Badge** (badge, "With Icon" demo) by coss.com: https://21st.dev/community/components/coss.com/coss-badge (21st.dev demo 11356). Used in `src/ui/badge.tsx` + `src/ui/badge-kinds.ts`; kept the cva size split, icon sizing and data-slot; replaced free colour variants with semantic kinds (tier-0..3, SAE, SAE clock, AESI, measured, simulated, draft states, query severity/status, UI feedback) that always render a Lucide icon + word; status token colours only; 12px text floor (was 10px); removed Base UI useRender polymorphism and the box-shadow transition.
- **Combo Kbd** (keyboard shortcut caps) by ai2: https://21st.dev/community/components/ai2/kbd-combo (21st.dev demo 28308). Used in `src/ui/kbd.tsx`; kept the root `<kbd>` + sr-only phrase + aria-hidden caps model and the Combo/Plus/Sequence variants; dropped Chain and Group; token colours, 12px floor, symbols spoken as words ("]" = "Right bracket").
- **Data Table** (data table) by arihantcodes: https://21st.dev/community/components/arihantcodes/data-table (21st.dev demo 27049). Used in `src/ui/data-table.tsx`; kept sortable `<th aria-sort>` headers, one Tab stop into the rows with arrow-key movement, Enter to open, Space to select, Escape to clear, the sr-only caption, the polite row-count live region, skeleton and empty states; rebuilt on TanStack Table v8 with our tokens (36px rows, 13px tabular cells, 12px uppercase headers, opaque `bg-surface`, `shadow-elev-1` sticky head); added j/k, whole-row link (click, Enter, Ctrl/middle click for a new tab), error state with Retry and server-side (`manualSorting`) sort; removed all motion (spring row reorder, sweep-out deletes, rolling totals, flip digits, press scale), column resize, search, quick-filter pills, clipboard copy, totals, disclosure rows and pagination.
- **Data Table Row Selection** (table row selection) by felipemenezes098: https://21st.dev/community/components/felipemenezes098/table-row-selection (21st.dev demo 22168). Used in `src/ui/data-table.tsx`; kept TanStack `rowSelection` state, select-all with an indeterminate state and the "N selected" bulk bar with Clear; changed to native checkboxes (no Radix checkbox dependency), per-row `canSelectRow` (disabled rows are named "not available"), caller-supplied bulk actions instead of the demo Delete.
- **Command Menu** (command palette, Layro System) by uvain: https://21st.dev/community/components/uvain/command-menu-palette (21st.dev demo 33510). Used in `src/ui/command-menu.tsx` + `src/ui/use-command-menu.ts`; kept cmdk inside a Radix dialog, grouped items with icon, hint line and shortcut caps, keywords, the sr-only title, the listbox/group ARIA repair and the keyboard legend, and the Ctrl/Cmd+K hook; changed to data-driven `items` + `groups`, `.glass-strong` panel with an opaque `bg-accent` highlighted item, 12px text floor (was 10.5-11.5px), shared `@/ui/kbd` caps, cmdk vim bindings off so Ctrl+K also closes, optional `/` shortcut (ignored while typing); removed the squircle corner-shape, zoom/fade animation and dark scrim.
- **Floating Header** (sticky glass navigation bar) by efferd: https://21st.dev/community/components/efferd/floating-header (21st.dev demo 8137). Used in `src/ui/app-header.tsx`; kept the frosted sticky bar with brand left, ghost nav links and a right action area; changed to a full-width 48px console bar (the rounded capsule survives only as `variant="floating"`), token `.glass` utility with solid fallback, `brand`/`nav`/`search`/`study`/`actions` slots, nav items with `aria-current` styling (semibold dark text + 2px teal underline) and count badges with screen-reader words, a skip link and a labelled nav landmark; removed the mobile drawer, the hover-duration brand effect and the mono logo.
- **Segmented Control** (view switcher) by kuratlielia: https://21st.dev/community/components/kuratlielia/segmented-control (21st.dev demo 35020). Used in `src/ui/segmented-control.tsx`; kept the options/value/onValueChange/label/accessory/onOptionIntent API, the roving tab stop (arrows wrap and select, Home/End) and scroll-selection-into-view; changed `aria-pressed` buttons to a WAI-ARIA radiogroup, Tailwind 3.4 + tokens instead of a CSS module, console sizes sm/md, per-option disabled (skipped by keys) and icon, generic value type; removed the motion/react gliding highlight, spring, smooth scroll and edge-fade mask (selected = white segment, 3:1 border, semibold).
- **Sonner Toast** (toast with Undo) by bundui: https://21st.dev/community/components/bundui/toast1 (21st.dev demo 19941). Used in `src/ui/toaster.tsx` + `src/ui/toast.ts`; kept sonner and the title + description + Undo action content model; every toast is now our own `ToastCard` (`toast.custom`) on `.glass-strong` with success/info/warning/danger Lucide icons and an sr-only tone word, our Button for Undo and Dismiss, `notify()` helpers with tone durations (danger stays until dismissed, action toasts >= 10 s); sonner slide/stack transforms replaced by a 200ms opacity fade, `expand` on, polite live region labelled "Notifications".
- **Sheet** (side/bottom dialog panel) by kevingirelli: https://21st.dev/community/components/kevingirelli/sheet (21st.dev demo 35214). Used in `src/ui/sheet.tsx`; kept the Radix Dialog base (focus in, trap, return; Esc and overlay close; scroll lock), part names, `side`, `showCloseButton`, `closeLabel`, `overlayClassName`; changed to `.glass-strong` inset panel with `rounded-sheet`, `shadow-elev-3`, 50% foreground-token scrim, sides right/bottom/left, sizes sm 384 / md 480 / lg 640, our Button as the close control, added `SheetBody` and bordered header/footer; removed the slide animations (no tailwindcss-animate) and the `top` side.
